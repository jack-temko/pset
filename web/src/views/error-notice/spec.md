# Error notice

purpose: mockups for F1 of the error catalog (`ideas/error-catalog-grill.md`). Four ways to show one failure, a short field form, and the Settings errors table. Static sample data, no backend.

where: `/views/error-notice`, one scenario per state. Code: `web/src/views/error-notice/`.

The sample failure everywhere: importing "Calculus" failed. Chain `import.failed`, `key.out_of_credit`, HTTP 402, incident `E7K2QF`.
